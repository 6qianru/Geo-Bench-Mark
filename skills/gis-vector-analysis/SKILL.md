# GIS 矢量空间分析技能包

适用范围：
- 缓冲区分析
- 空间查询
- 叠置分析
- 结果输出说明

执行原则：
1. 先确认数据、距离、单位和输出要求。
2. 先读入口文件，再按需加载 references。
3. 涉及缓冲区分析时，必须先读取相关 reference。
4. 不得凭记忆猜测未读取 reference 的内容。
5. 完成任务时使用 `[FINAL]` 返回结果数据句柄和简要说明。

按需加载规则：
- 任务开始时优先读取执行计划和数据确认 reference。
- 当任务涉及缓冲区分析时，必须读取 `references/01_缓冲区分析.md`。
- 输出结果前应读取 `references/10_结果展示.md`。
